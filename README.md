# My Desktop Config
## dwm
<img align="right" height="192" width="341" src="https://github.com/diws1/dots/blob/main/screenshot/dwm_new.png" alt="image" />
<b>dwm</b> is the main window manager I use. I only apply a few patches that I need, leaving dwm to be simple without reducing its performance. As a system indicator on the bar I use <b>sxstatus</b> instead of using other statusbars. You can configure it further by adding some patches that you need, for example if you want to add color to sxstatus you may need patches like <b>status2d</b> in the dwm source code.

The applications need to install:
- Panel: [sxstatus](https://github.com/diws1/sxstatus)
- Launcher: dmenu
- Terminal: alacritty, terminator
- Fonts: Liberation Mono, Noto Color Emoji
- Wallpaper: nitrogen

## i3
<img align="right" height="192" width="341" src="https://github.com/diws1/dots/blob/main/screenshot/i3_new.png" alt="image" />
In addition to <b>dwm</b> I also use the <b>i3</b> window manager. In addition to having various features, i3 provides user convenience in configuring with just one config file, lots of tutorials on the internet, and documentation support. As a system indicator on the bar I use <b>polybar</b> and add some colors to the icons. You can also use <b>i3status</b> as a statusbar, maybe you like the appearance of i3status in my <b>i3</b> repository.

The applications need to install:
- Panel: polybar
- Launcher: dmenu
- Terminal: alacritty
- Fonts: Liberation Mono, Liberation Mono Nerd Font
- Wallpaper: feh
